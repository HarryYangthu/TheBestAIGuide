# 范围与边界

- AI、机器学习、深度学习和强化学习基础。
- 基础模型、LLM、多模态模型及其训练与推理机制。
- Agent 的 Context、Tools、RAG、Memory、Planning、Workflow 和 Multi-Agent。

- 可复现实验、可测试代码、真实案例、失败复盘和一手来源。
