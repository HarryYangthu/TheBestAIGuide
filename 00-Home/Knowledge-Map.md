# Agent 组件地图

当前结构以 [12 个核心组件与 3 个增强能力](../10-Knowledge/README.md) 为主线。每个组件负责执行过程中的一类具体问题，完整系统图和目录状态统一在组件总览维护。

| 关注的问题 | 对应组件 |
|---|---|
| 要做什么，怎样算完成 | 01 任务与协议、10 评估与验收 |
| 如何决定和执行下一步 | 02 模型接入、03 执行循环、08 工具与环境 |
| 多个执行者如何配合 | 04 编排与调度、05 通信与交接 |
| 当前可见什么，进度与成果在哪 | 06 上下文、07 状态与产物 |
| 中断或失败之后如何处理 | 09 持久化与恢复、11 Trace 与可观测性 |
| 哪些动作允许执行，资源还有多少 | 12 权限与资源控制 |
| 如何跨任务复用与改进 | 13 Memory、14 Skills、15 自进化 |

第 03 章先实现单 Agent 的执行循环。Harness 则是这些组件围绕一次运行的组合，可结合[归档中的源码走读](../10-Knowledge/_archive/09-runtime-harness-environment/01-concepts/01-runtime-and-harness.md)理解。

AI 基础、基础模型、RAG、生产工程等原有主题保存在[旧知识体系总纲](../10-Knowledge/_archive/knowledge-map.legacy.md)。它们作为查阅材料与前置知识，后续按需要接入组件章节。
