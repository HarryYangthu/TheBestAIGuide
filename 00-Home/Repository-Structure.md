# 仓库目录说明

TheBestAIGuide 仓库本身就是知识库根目录，不再使用额外的 `knowledge-tree/` 包裹层。

| 目录 | 内容 |
| --- | --- |
| `00-Home/` | 总入口、范围、规范和状态 |
| `10-Maps/` | 各主题知识地图（MOC） |
| `20-Knowledge/` | 概念、原理和知识结论 |
| `30-Patterns/` | 可复用设计模式和工程取舍 |
| `40-Cases/` | 系统案例、代码仓走读和失败复盘 |
| `50-Labs/` | 可运行的 Jupyter 实验 |
| `60-Code/` | 可复用、可测试的源码工程 |
| `90-Sources/` | 论文、文档、标准和代码仓来源 |
| `99-Inbox/` | 尚未整理和归类的材料 |
| `assets/` | 文档引用的图片和图表 |

## 内容边界

- Markdown 保存知识结论和引用。
- Notebook 保存实验过程、参数、输出和结论。
- 标准源码工程保存需要复用或自动测试的实现。
- 案例用于连接原理与真实系统，不替代通用知识笔记。
- 占位内容不代表功能已实现或结论已验证。
