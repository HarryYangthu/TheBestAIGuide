# 建设路线

本轮已补齐原脚手架的教学主线：基础与模型、Agent 与信息链路、系统执行与评测、应用生产及研究方向。具体文件和实际运行结果见[建设状态](Knowledge-Status.md)。

## 后续按学习收益迭代

1. 读者先跑现有实验，把不理解的段落和失败输入记入 Inbox；优先修这些问题。
2. 在保持离线教学基线的同时，逐步增加真实模型适配器和独立问题集，分别测模型、检索与运行时。
3. 对需要 GPU、人工标注或真实外部环境的研究结论，单独记录资源、版本、数据和复现范围。
4. 根据月度链接检查维护来源；依赖升级后跑现有回归，不只替换版本号。

以上是持续学习与维护方向，不把尚未做的外部实测计入本轮交付。详见[完成与后续计划](待补充计划.md)。
