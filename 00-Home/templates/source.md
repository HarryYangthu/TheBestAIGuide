# 〈来源名称〉

> 这是可复制来源卡模板，尚不是来源核验记录。复制后删除此提示，替换全部 `〈…〉`；可直接放入领域 `references.md` 的一个小节。

| 字段 | 内容 |
| --- | --- |
| 一手入口 | 〈作者／官方项目／标准机构的实际 URL〉 |
| 固定版本 | 〈论文 vN、标准修订、书籍版次、发布版本或完整提交 SHA〉 |
| 发布／修订日期 | 〈来源提供的日期；找不到则写未确认〉 |
| 本次读取日期与范围 | 〈日期；摘要／指定章节／指定函数／实际实验〉 |
| 关联知识点 | 〈仓库实际相对链接〉 |
| 许可或复用条件 | 〈仅链接／原始许可及定位；未核验则如实写明〉 |

## 它支持哪项判断

〈用自己的话概述所需结论，定位到章节、公式、表格或固定源码路径。不要将作者观点改写成普遍事实。〉

## 证据条件与限制

〈记录模型、数据、预算、评测方式或实现版本。分清原文结论、本库推断和本库运行结果；未读全文或未复现的部分明确注明。〉

## 怎样连接实践

〈链接使用该结论的文章、实现和实验；若只是阅读入口，无配套复现就写明。来源更新后，列出需要重新核对的具体行为或参数。〉
