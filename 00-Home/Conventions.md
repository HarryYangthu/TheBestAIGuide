# 目录与写作规范

## 命名

- 一级目录使用数字前缀稳定排序。
- 技术目录使用小写英文 `kebab-case`，正文默认使用中文。
- 同一知识点只保留一个正式定义，其余位置通过链接引用。

## 链接

- 仓库内统一使用相对链接。
- 图片统一放在 `assets/`。
- 移动文件时必须同步检查 Markdown 与 Notebook 链接。

## 内容状态

- `seed`：主题边界或占位。
- `draft`：已有正文，尚未完成审查。
- `reviewed`：结构、事实和来源已审查。
- `verified`：相关代码或实验已实际运行。

## 证据边界

- 总纲中出现一个术语，不等于已经有完整专题。
- 文档中的代码片段，不等于可运行工程。
- Notebook 能打开，不等于实验已验证。
- 架构设计，不等于生产系统已经运行。
