# 内容使用方法

## 阅读

从 `10-Maps/` 进入主题，通过相对链接阅读 `20-Knowledge/` 中的正式笔记。遇到设计取舍时查看 `30-Patterns/`，需要真实背景时查看 `40-Cases/`。

## 实验

`50-Labs/` 用于修改参数、观察输出和保存实验结论。只有实际执行并记录环境与结果的 Notebook 才能标记为 `verified`。

## 代码

`60-Code/` 保存需要复用和自动测试的实现。Notebook 中稳定的逻辑应提取到源码工程，不在多个 Notebook 中复制维护。

## 新内容进入知识库

```text
99-Inbox
  -> 90-Sources
  -> 20-Knowledge
  -> 30-Patterns / 40-Cases
  -> 50-Labs / 60-Code
  -> 回写 10-Maps
```
