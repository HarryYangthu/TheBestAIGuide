# Evaluation Patterns

本目录保存可复用的评测设计模式。当前专题已经覆盖这些模式的原则，后续再拆为独立卡片：

- Golden Dataset：由真实任务、边界与事故构成的版本化任务集。
- Multi-trial：用重复运行和区间描述非确定性。
- Judge Calibration：用人工标注集检查模型评分器的一致性与漂移。
- Outcome Verification：优先验证文件、数据库和系统真实状态。
- Shadow Evaluation：在真实分布上评估但不执行生产副作用。
- Release Gate：硬门禁、非劣比较和成本权衡分层决策。
