# Evaluation 教学任务

> 状态：verified
> 数据版本：teaching-eval-v1；2026-09-06；人工构造，无真实业务数据。

[tasks.jsonl](tasks.jsonl)包括合法读取、错租户、旧版本、缺失版本四条 Task。标签直接来自本案例定义的功能规格；公开给学习者，不称作独立测试集。每个 Trial 深拷贝 `lookups=0` 的初始状态，最终必须为 1。

被测代码只能接收 `input` 与复制的 `fixture`；`expected` 留给 Grader。测试中的评分反例为人工构造：布尔/整数混用、声称成功但未写状态、禁止字面值出现在输出、版本不匹配等。

这些数据不含独立专家标签，不用于模型 Judge 校准。一旦用于真实评测，应补来源授权、脱敏记录、任务族划分、独立标签、版本与评分器变更记录；不能把公开 toy fixture 的通过率当生产能力。
