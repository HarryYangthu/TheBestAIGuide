# 强化学习：学习动作如何改变后续收益

> 状态：draft · 来源核验：2026-09-06 · 实验是五格有限环境，非真实 Agent 强化训练。

监督学习通常告诉模型“这个输入应该输出什么”；强化学习让策略采取动作，再从环境反馈中学习。关键困难是动作可能改变后续遇到的数据，而且一个错误动作要到很久之后才暴露。只在最终答案上打分，并没有自动解决中间动作的信用分配。

## 1. MDP 把什么假设写进了问题

马尔可夫决策过程为 $(\mathcal S,\mathcal A,P,R,\gamma)$。$s$ 是状态，$a$ 是动作，$P(s'\mid s,a)$ 是转移概率，$R$ 给出奖励，$\gamma$ 是折扣因子。马尔可夫假设要求：给定当前状态和动作，未来不再需要更早历史。如果“当前状态”只有最后一句话，却遗漏用户约束，通常不满足这个要求。

部分可观测过程 POMDP 中，智能体看到观测 $o_t$，不一定知道真实状态。可以维护信念 $b_t(s)=P(s_t=s\mid o_{\le t},a_{<t})$，在模型已知时根据转移与观测似然更新；大环境中常用历史或循环网络近似。记忆在这里帮助补足状态，不意味着越长历史越好。

策略 $\pi(a\mid s)$ 给出动作分布。回报为：

$$G_t=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots.$$

例如先付出代价 -1，两步后得到 10，$\gamma=0.9$ 时回报是 $-1+0.9\times0+0.9^2\times10=7.1$。折扣决定远期收益的权重，不是“奖励归一化”。无限期问题中 $\gamma<1$ 常帮助保证回报有界；有限回合也可用 $\gamma=1$，但必须正确终止。

## 2. V 与 Q 区别在哪里

$V^\pi(s)=E_\pi[G_t\mid s_t=s]$ 评价进入某状态后的长期收益；$Q^\pi(s,a)=E_\pi[G_t\mid s_t=s,a_t=a]$ 评价先执行某动作、再遵循策略的收益。所以 $V^\pi(s)=\sum_a\pi(a\mid s)Q^\pi(s,a)$。

Bellman 方程把整条未来拆成“这一笔奖励＋下一状态的价值”：

$$V^\pi(s)=\sum_a\pi(a\mid s)\sum_{s',r}p(s',r\mid s,a)[r+\gamma V^\pi(s')].$$

最优价值把策略加权换成对动作取最大：

$$V^*(s)=\max_a E[r+\gamma V^*(s')\mid s,a].$$

教学环境有五个位置 0…4，每次向左或右，进入 4 获奖励 1 并终止，其余奖励为 0。$\gamma=0.9$，最优值为 $[0.729,0.81,0.9,1,0]$。终止位置值为 0，因为奖励已经在“进入它”时支付；若又给终点价值 1，就重复计算了收益。

## 3. 已知规则就规划，未知规则用经验更新

价值迭代需要转移模型，对所有状态反复应用最优 Bellman 更新；这是 model-based 方法。Model-free 方法直接从采样 $(s,a,r,s')$ 学价值或策略，不要求显式学习环境转移，但不等于不需要环境交互。

Q-learning 的一次更新为：

$$Q(s,a)\leftarrow Q(s,a)+\alpha\big[r+\gamma(1-d)\max_{a'}Q(s',a')-Q(s,a)\big].$$

$\alpha$ 是步长，$d$ 表示真实终止。括号内是 TD error：当前估计与一步自举目标的差。假设原 $Q=0.2$、$r=0$、下一状态最大值 0.8、$\gamma=0.9,\alpha=0.5$，新值是 $0.2+0.5(0.72-0.2)=0.46$。

```python
next_state, reward, done = env_step(state, action)
target = reward + gamma * (not done) * q[next_state].max()
q[state, action] += alpha * (target - q[state, action])
```

Q-learning 的目标假设下一步选择最大 Q 动作，但采样策略可能仍在随机探索，所以是 off-policy。SARSA 用实际采样的下一动作 $a'$ 建目标，评价正在执行的策略，是 on-policy 的经典例子。回合因外部时间限制截断与环境真正终止不同：若任务继续，截断处可能仍需 bootstrap，不能一律把下游值清零。

## 4. 探索与信用分配为什么容易失败

$\epsilon$-greedy 以概率 $\epsilon$ 随机选动作，否则选当前最优动作。初始 Q 全为零时，固定 `argmax` 会一直偏向编号小的动作；没有探索可能永远看不到奖励。理论收敛还需要访问条件与合适步长序列，不能把有限轮、固定步长实验称为一般收敛证明。

奖励稀疏时，长动作序列的成功信号传播很慢。可以缩短课程、增加合法过程信号、使用多步目标或资格迹，但中间奖励必须与最终任务一致。只奖励“调用测试工具”，策略可能反复调用而不修复问题；只奖励文本判断器满意，可能学会迎合判断器。信用分配与奖励定义是两件需要分别验证的事。

训练和评估要分开：评估冻结参数、关闭无意探索，在未参与调参的环境种子和任务上比较规则基线。至少记录成功率、回报、步数、预算超限和非法动作。更高回报不一定意味着业务更好，先检查奖励是否和业务目标一致。
