# Memory 与 State

> 状态：seed

本领域区分当前任务的权威运行事实和跨步骤、跨会话保存的信息，避免把完整聊天历史、数据库和 Memory 混为一谈。

## 建议顺序

1. State、Session、Checkpoint 与 Memory 的边界。
2. Working、Episodic、Semantic 和 Procedural Memory。
3. 写入判定、检索、更新、冲突、遗忘与删除。
4. 来源、时效、权限、隐私和跨用户隔离。
5. Memory Eval：任务收益、错误记忆、污染和长期退化。
6. [实验入口](04-labs/README.md)。

当前只有范围占位。建议先完成[Context Engineering](../04-context-engineering/README.md)，再学习本领域。
