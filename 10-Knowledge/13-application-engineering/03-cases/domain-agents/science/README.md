# 科研 Agent：让模型提假设，让实验决定结论

> 状态：draft · 更新：2026-09-06

教学任务在宽度 `[4,8,16]` 中寻找参数预算不超过 100 的候选。本例人为规定参数量为宽度平方、损失为 `1/(width+1)`，所有数据都是合成的。目的在于理解候选、约束、实验与结果的接口，不是模拟真实神经网络性能。

[代码](../../../05-code/application_cases.py)的 `science_search` 先过滤参数量，再对合法候选比较损失。结果选宽度 8、参数 64、合成 loss 约 0.1111；宽度 16 参数 256，不能因为合成 loss 更小就突破约束。这个结果来自实际运行的确定性枚举，不是模型推理或新架构发现。

$$x^*=\arg\min_{x\in\mathcal X,\;P(x)\le100}L(x).$$

$\mathcal X$ 是候选集合，$P$ 是参数量计算，$L$ 是评价函数。真实实验必须用独立代码统计参数、固定数据划分和评价脚本；模型口头报告的参数量与 loss 不能成为验收事实。

| 系统角色 | 可以负责 | 不能独自决定 |
|---|---|---|
| Idea/Planner | 文献整理、假设与预算分配 | 实验结果是否真实 |
| 搜索程序 | 枚举、优化、资源过滤 | 研究问题是否有价值 |
| Executor | 固定配置执行并归档 | 随意改变评价标准 |
| Evaluator | 检查约束与指标 | 把开发集最优等同于泛化 |

反例包括：候选全部超预算、训练与评测数据重叠、不同候选训练时长不同、失败运行被悄悄丢弃。最小实现已对无可行候选抛错；这个枚举算例没有训练环节。若要继续看实际训练，[工作台科研任务](../../../../../20-Projects/learning-workbench/README.md)在 80 个构造样本上拟合线性模型，用另 40 个样本比较均值基线，并保存数据、划分、训练 loss 和验证 MSE。它研究的是线性拟合，不是本篇网络宽度选择，两个实验的指标不能拼成同一个寻优成绩。公开研究流程参考[The AI Scientist v1](https://arxiv.org/abs/2408.06292v1)，更详细的归档与评审机制见[Research Agent 案例](../../../../16-research-frontiers/03-cases/01-research-and-science-agents.md)。
