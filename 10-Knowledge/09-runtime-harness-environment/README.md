# Runtime、Harness 与 Environment

> 状态：seed

本领域解释 Agent 如何从“模型会生成动作”变成能够可靠执行、恢复和审计的系统。

## 建议顺序

1. Run、Step、Event、State 和 Artifact 生命周期。
2. Timeout、Retry、Idempotency、Cancellation 与 Compensation。
3. Checkpoint、Resume、Replay 和 Durable Execution。
4. Queue、Concurrency、Rate Limit 与 Backpressure。
5. Workspace、Sandbox、代码执行、Browser 和 Computer Use。
6. Harness 的权限、Trace、预算和人工审批职责。
7. [实验入口](04-labs/README.md)。
