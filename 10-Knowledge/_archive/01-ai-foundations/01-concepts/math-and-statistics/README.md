# 数学与统计：把模型写成可以检查的计算

> 状态：draft · 来源核验：2026-09-06 · 实验为合成教学数据，见文末。

假设我们要用两个输入特征预测一个数值，例如用请求长度和工具次数估算处理时间。数学首先帮助我们写清楚“谁与谁运算”，然后检查误差如何产生、如何缩小。它不是需要背完才能写代码的前置词典。

## 1. 向量、矩阵和张量分别装什么

一个样本有 $d$ 个特征，写成 $x\in\mathbb R^d$；$n$ 个样本按行堆起来得到 $X\in\mathbb R^{n\times d}$。权重 $w\in\mathbb R^d$ 把每个特征的贡献相加，预测为 $\hat y=Xw$，形状是 $(n,)$。偏置可以单独写成 $b$，也可以在 $X$ 第一列补全 1，让 $w_0$ 充当偏置。

例如 $x=[2,3]$、$w=[4,-1]$，预测是 $2\times4+3\times(-1)=5$。点积做的是“逐维相乘再求和”；它可以表示加权和或匹配分数，但没有归一化时不是统计学相关系数。余弦相似度 $x^Tw/(\|x\|\|w\|)$ 去掉了长度影响，零向量需要单独处理。

矩阵乘法 $C=AB$ 中，$A:(m,d)$、$B:(d,k)$、$C:(m,k)$，$C_{ij}=\sum_r A_{ir}B_{rj}$。张量只是多了有语义的轴，例如一批文本的表示是 $(B,T,D)$：样本、位置、通道。写代码前标注轴，比出错后猜 `reshape` 有用。

```python
import numpy as np
X = np.array([[1., 2.], [1., 3.]])  # 两个样本；第一列是偏置
w = np.array([1., 2.])
y_hat = X @ w                     # [5., 7.]，不是 X * w
assert y_hat.shape == (2,)
```

需要注意 NumPy 的广播：$(n,1)-(n,)$ 会得到 $(n,n)$，程序可能运行而损失完全错误。训练入口应检查标签形状。解线性方程用 `solve` 或 `lstsq`，不显式求逆；特征高度相关时矩阵接近奇异，微小噪声会造成很大的权重变化。

## 2. 概率描述不确定性，统计描述我们知道多少

概率 $P(Y=1\mid X=x)$ 是给定输入下事件发生的程度；模型输出一个 0.9，并不自动说明这个 0.9 已经校准。期望 $E[Z]=\sum_z p(z)z$ 是按概率加权的平均；方差 $\operatorname{Var}(Z)=E[(Z-EZ)^2]$ 描述波动。样本均值的标准误约为 $s/\sqrt n$，前提是独立同分布且方差有限。把同一任务的十次重试当成十个独立用户，会低估不确定性。

贝叶斯公式把“先验”和“观察到的证据”结合：

$$P(H\mid E)=\frac{P(E\mid H)P(H)}{P(E\mid H)P(H)+P(E\mid\neg H)P(\neg H)}.$$

教学例：故障率 1%，检测器对故障有 90% 检出率，对正常设备有 5% 误报率。看到告警后故障概率为 $0.009/(0.009+0.0495)\approx15.4\%$。不能把 90% 检出率直接当作“告警可信度”；基率不同，后验也不同。

协方差 $E[(X-EX)(Y-EY)]$ 反映共同变化，相关不证明因果。例如长任务既需要更多 token 又更容易失败，不能据此断定删除 token 会提高成功率。要比较上下文策略，应该让两种策略运行同一批任务，并尽量只改变该策略。

## 3. 为什么训练常用对数损失

一个真实类别是 $y$ 的样本，模型给它概率 $p_y$，负对数似然为 $-\log p_y$。给正确类别 0.8，损失约 0.223；只给 0.01，损失约 4.605。对数把多个独立样本的概率乘积变成损失的加法，也对“自信地错”施加较大代价。

一般的交叉熵 $H(p,q)=-\sum_i p_i\log q_i$ 用目标分布 $p$ 衡量预测分布 $q$。当标签是 one-hot 时，只剩正确类那一项。它满足 $H(p,q)=H(p)+D_{KL}(p\|q)$，固定目标时减小交叉熵等价于减小此方向的 KL。KL 不对称，也不是满足三角不等式的距离；$p_i>0,q_i=0$ 时会发散。实现从 logits 直接使用 log-sum-exp，避免先得到下溢的零概率再取对数。

## 4. 梯度究竟在算什么

用半均方误差训练线性模型：

$$L(w)=\frac1{2n}\|Xw-y\|_2^2,\qquad \nabla_w L=\frac1nX^T(Xw-y).$$

令残差 $r_i=\sum_jX_{ij}w_j-y_i$。对一个参数 $w_j$ 求导，$\partial(r_i^2/2)/\partial w_j=r_iX_{ij}$；再对样本求平均，就得到上式。梯度的第 $j$ 维告诉我们：这个参数增加一点，损失将如何变化。

梯度下降 $w\leftarrow w-\eta\nabla L$ 中，$\eta$ 是学习率。对最简单的 $L(w)=w^2/2$，更新为 $w_{t+1}=(1-\eta)w_t$；只有 $0<\eta<2$ 才会收敛到零。学习率过大不是“学得快”，而是在最低点两侧越跳越远。一般二次函数还受最大曲率影响，特征尺度差异会使合适步长变得更难选。

```python
y = np.array([4., 8.])    # 独立目标，与前面预测 [5., 7.] 比较
residual = X @ w - y       # [1., -1.]
loss = (residual @ residual) / (2 * len(X))
gradient = X.T @ residual / len(X)
w = w - 0.1 * gradient     # [1., 2.05]，第二个参数实际发生变化
```

梯度检查用有限差分 $g_j\approx[L(w+\epsilon e_j)-L(w-\epsilon e_j)]/(2\epsilon)$。这能发现漏掉样本平均、转置错误等问题；$\epsilon$ 过小会受到浮点消减误差影响，过大则不再是局部近似。它适合小样本调试，训练仍用自动微分。

## 5. 一个结果怎样才值得相信

实验先确定独立抽样单位、训练/验证/测试划分和主指标。比较两个方法时记录每个任务的差值 $d_i$，平均改进为 $\bar d$，而不是只看两张汇总表。独立样本足够多时可用标准误估计区间；样本相关时按用户、设备或任务族分组重采样。调过参数的验证集不能再充当最终测试集。

常见错误与修复：矩阵形状不对就加维度，应该先写出轴含义；均值上升就宣称有效，应该检查波动和失败子集；把 $p$ 值理解成“假设为真的概率”，应该把它理解为零假设下观察到如此或更极端统计量的概率；只固定随机种子就宣称完全可复现，还需要数据版本、依赖和运行环境。
