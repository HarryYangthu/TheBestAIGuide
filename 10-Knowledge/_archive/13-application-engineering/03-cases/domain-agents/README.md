# 领域 Agent：共享执行骨架，不共享业务验收

> 状态：draft · 更新：2026-09-06

领域 Agent 可以共享模型适配、工具调用和运行状态，但是否完成任务必须按业务定义。下面三个案例用本库原创数据解释业务边界，均未连接真实企业系统。

| 案例 | 输入与目标 | 决定成败的证据 | 进入学习 |
|---|---|---|---|
| 企业知识 | 员工查询预算规则 | 权限内文档与来源 | [企业案例](enterprise/README.md) |
| 运维诊断 | 发布后错误率上升 | 指标、时间线与变更证据 | [运维案例](operations/README.md) |
| 科研寻优 | 资源约束内比较候选 | 配置、运行记录与独立评价 | [科研案例](science/README.md) |

代码统一放在[application_cases.py](../../05-code/application_cases.py)，从仓库根目录可直接运行。它们是用于讲解检索隔离、建议生成和确定性搜索的小函数；完整 Agent 还需要模型决策、真实工具适配、持久运行与评测集。阅读时先明确案例验证的局部机制，再把接口接入[应用后端](../../01-concepts/01-backend-and-streaming.md)。
