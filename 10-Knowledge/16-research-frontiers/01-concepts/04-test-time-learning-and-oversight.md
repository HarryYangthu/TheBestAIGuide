# 推理时学习与监督：加上下文、加计算、改参数是三件事

> 状态：draft · 来源核验：2026-09-06 · 教学示例均为本库原创，非生产成绩。

> 研究快照：2026-09-06；TTT 使用 2024-07-05 v1，Titans 使用 2024-12-31 v1。

“模型在使用过程中学习”可能指完全不同的行为。给上下文加一条经验、让模型多尝试几次、更新一个神经记忆模块，状态变化与风险都不同。

| 名称 | 推理时变化 | 是否一定更新主模型权重 |
|---|---|---|
| In-context learning | 输入中的例子或说明 | 否 |
| 检索记忆 | 外部数据及召回内容 | 否 |
| Test-time compute | 候选数、搜索、验证次数 | 否 |
| Test-time training/adaptation | 某些参数或学习状态 | 是参数更新，但不一定是全部主模型 |
| TTT 层/神经记忆 | 序列内部的可学习隐状态 | 不能简单等同于全模型在线微调 |

## TTT 的关键直觉

传统 RNN 用固定规则更新一个向量隐状态。TTT 研究把隐状态本身视为一个小模型，用当前输入构造自监督目标，再通过学习步骤更新它。抽象形式为：

$$W_t=W_{t-1}-\eta\nabla_W\ell(W_{t-1};x_t).$$

$W_t$ 是该序列的学习状态，$x_t$ 是当前输入，$\eta$ 是步长，$\ell$ 是架构定义的自监督损失。这不是说拿到任意用户提问后，就可以直接用用户答案更新通用模型。目标如何构造、哪些状态跨 token 保存、如何训练这些更新机制，都是方法的一部分。

用标量损失 $\ell(w;x)=\frac12(w-x)^2$ 说明一次更新：从 $w=0$ 读到 $x=2$，取 $\eta=.5$，得到 $w'=1$。这只是梯度更新直觉，不是 TTT 层完整复现。

```python
w, x, eta = 0., 2., .5
w = w - eta * (w-x)
assert w == 1.
```

[TTT v1](https://arxiv.org/abs/2407.04620v1)研究上述可学习隐状态方向；[Titans v1](https://arxiv.org/abs/2501.00663v1)研究推理时神经长期记忆与注意力的组合。两者都需要专门架构与训练，不能只在普通 API 调用外加一段 Prompt 就声称实现。

## 监督与适应的冲突

推理时适应可能让系统追随错误输入。对多租户服务，序列内学习状态是否重置、是否跨用户共享、更新是否可撤回，必须明确定义。记录“变化对象—数据来源—保存期限—回滚路径”，把可变状态与只读验证器分开。

Best-of-N 生成多个候选再由验证器选择，也有监督瓶颈：若评分器偏爱表面格式，候选越多越可能找到高分漏洞。应在相同计算预算下报告结果，并用独立标准检查获胜候选。[奖励投机篇](../../12-agent-learning/01-concepts/04-verifiers-and-reward-hacking.md)和[实验](../../12-agent-learning/04-labs/01-trajectories-and-rewards.ipynb)给出可运行反例。[研究算例](../05-code/research_checks.py)演示标量更新和状态重置，未复现论文训练结果。
