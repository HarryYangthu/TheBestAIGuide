# Assets

本目录保存 Markdown 引用的图片、SVG 和图表。

## 当前状态

- `context-engineering-core.svg`：当前正文使用的可编辑示意图，文件内包含无障碍 `title` 和 `desc`。
- `context-engineering-core.png`：同主题历史位图，当前未引用。
- `context-clash-sharded-instruction.png`、`tool-calling-irrelevance-score-gemma.png`：历史素材，来源信息尚未补齐，当前未引用。
- `evaluation-*.png`：旧 Evaluation 长文使用的历史素材，当前未引用；恢复使用前需确认原始出处和复用条件。

## 规则

- 文件名描述内容，不使用 `image-1.png` 之类无语义名称。
- 每处 Markdown 引用必须提供有效替代文本。
- 外部图片在引用处或本文件记录作者、原始 URL、日期和许可信息。
- 自制图保留可编辑源文件；位图衍生物说明生成来源。
- 来源不明的历史素材不得进入正式正文，确认无保留价值后再单独清理。
