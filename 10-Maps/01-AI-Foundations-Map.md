# AI 基础知识地图

> 状态：seed

AI 基础只收录理解和实现现代 Agent 所需的核心底座，不扩展成完整的人工智能学科百科。

## 主线

```text
数学与统计
  -> 机器学习
  -> 深度学习
  -> 搜索、规划与强化学习
  -> 基础模型
  -> Agent
```

## 知识模块

1. 数学与统计：向量、矩阵、张量、概率、统计、信息论、梯度和优化。
2. 机器学习：学习范式、任务类型、Loss、Metric、数据划分、泛化和分布偏移。
3. 深度学习：计算图、自动微分、反向传播、训练循环、优化器和表示学习。
4. 经典 AI：状态空间、搜索、启发式、约束满足、规划和概率推理。
5. 强化学习：MDP/POMDP、Policy、Value、Q、Bellman、探索与奖励设计。
6. 可信 AI：不确定性、校准、鲁棒性、公平性、可解释性、隐私和模型安全。
7. 计算基础：CPU/GPU、显存、带宽、数值精度、训练与推理的资源约束。
