# 我的 Mini Agent 实验记录模板

复制本文件到自己的实验目录填写。下面是有意留给学习者记录的模板，不是已运行结果。

| 项目 | 我的记录 |
| --- | --- |
| 日期、代码提交 | 待记录 |
| Python 版本 | 待记录 |
| 模式与模型 | demo 或 live；live 填模型标识，不填密钥 |
| 运行命令与输出目录 | 待记录 |
| 清单与验收报告 | 填实际文件位置与 PASS/FAIL |
| 第一次失败发生在哪里 | 填 trace 中的工具调用或验收项目 |
| 我修改了什么，为什么 | 指向具体代码或输入 |
| 修改前后的结果 | 填调用次数、验收差异；不要编造成功率 |
| 当前实验不能证明什么 | 例如：只跑了一个固定任务，没有验证新资料 |

完成自查：能指出模型请求与工具结果的配对；能解释上下文被移除的内容；能验证跨进程记忆；能区分工具并发和子 Agent；能主动制造一个会被验收拒绝的错误。
