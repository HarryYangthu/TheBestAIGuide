# Knowledge Tree

这里是 TheBestAIGuide 的知识主体。

当前阶段先建立稳定的目录边界，现有文档暂时保留在本目录根部；后续整理时再逐篇迁移，避免一次性移动造成链接失效。

## 目录约定

| 目录 | 内容 |
| --- | --- |
| `00-Home/` | 总入口、阅读说明和知识库状态 |
| `10-Maps/` | 各主题的知识地图（MOC） |
| `20-Knowledge/` | 概念、原理和结论 |
| `30-Patterns/` | 可复用的设计模式与工程取舍 |
| `40-Cases/` | 系统案例、代码仓走读和实验复盘 |
| `50-Labs/` | 可运行的 Jupyter 实验 |
| `60-Code/` | 可复用、可测试的 Python/TypeScript 工程 |
| `90-Sources/` | 论文、文档和代码仓等来源笔记 |
| `99-Inbox/` | 尚未整理和归类的材料 |

## 当前约束

- Markdown 保存知识结论。
- Notebook 保存实验过程和必要输出。
- 标准源码工程保存可复用实现与测试。
- 占位内容不代表功能已经实现或实验已经验证。
